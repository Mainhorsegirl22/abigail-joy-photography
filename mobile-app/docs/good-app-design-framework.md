# What good app design looks like

Reference framework, saved from a video walkthrough. Pipeline for taking a raw
idea to a shippable MVP:

```
Raw idea → Core Function → Core Loop → Accessory Features → Surface Area Check → Retention Hook → Shippable MVP
```

## 1. Core Function
- **Do:** Define the ONE thing the app does.
- **Check:** Can you say it in one sentence? If no, stop — the idea isn't ready.

## 2. Core Loop
- **Do:** Map the action → reward cycle, under 30 seconds.
- **Check:** Is it repeatable? If not, it's not a loop.

## 3. Accessory Features
- **Do:** Add only what supports the core loop.
- **Check:** Does it serve the loop? If no, cut it.

## 4. Surface Area Check
- **Do:** Count screens — max 5-7.
- **Check:** Over 7? Trim.

## 5. Retention Hook
- **Do:** Create an unfinished state (a reason to come back).
- **Result:** → Shippable MVP.
